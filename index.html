Personal project, 2026

RepoSage: ask questions about any codebase

Point it at a GitHub repo and ask questions in plain English, like where authentication is handled. It splits the code along function and class boundaries, embeds it with Gemini into pgvector, ranks matches by meaning and by keyword, and answers only from what it found, with citations that are checked before you see them.
